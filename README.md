
# The World's Easiest Game

**You can't lose this!**

This game is super easy. All you have to do is wait thirty seconds and this ~~_super boring easy game is over_~~ **super fun game** **is** **beaten**. But whatever you do, don't press the button in the middle. It does things you would never want. Why would you ever want that? So all you need to do is wait thirty seconds. Nothing more, nothing less. Very simple. But in reality, you should really ~~_press that button_~~ **not press that button**!
