## Features
- 10 unique microgames, with a level up system to upgrade difficulty.
- Fully fledged dialogue based on gameplay and saved between game sessions.
- Automatic music system with different levels based on point in game.
- Many sound effects to add immersion into the game.
- Full controller support for all microgames. (except Spell the Country)
- Custom cursor for more immersion into the game.
- A pause menu to head back to menu or quit the game while playing.
- Full main menu and splash screen.
- Settings menu to adjust volume that is saved between game sessions.

## Controls
**W, S, A, D, Arrow Keys, D-Pad, Left Joystick:** Move (Collect the Coins, Kill the Zombies)

**Left Mouse Button, Right Trigger, Playstation X, Xbox & Nintendo A:** Shoot (Kill the Zombies)

**Left Mouse Button, Space, Playstation X, Xbox & Nintendo A:** Jump (Dodge the Pipes)

**You should probably click all buttons you see on screen.**
